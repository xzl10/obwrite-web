Obwriteはすべての環境に対応する汎用アプリではありません。以下の条件に合わない場合は購入しないでください。

## 必要な環境

| 項目 | 必要条件 |
|---|---|
| OS | Windows 10 / Windows 11（64-bit） |
| ブラウザ | Google Chrome 最新版 |
| 保存先 | ローカルのObsidian Vault |
| 提供物 | Obwrite.exe、スタートアップマニュアル |

環境構築は不要です。ダウンロードした`Obwrite.exe`を起動して使用します。

## 公式サポート対象外

- macOS
- Linux
- スマートフォン、タブレット
- Google Chrome以外のブラウザ
- クラウド上だけに存在し、ローカルパスを持たない保存先

内部構造上の移植可能性と、実機で動作確認済みの公式サポートは別です。現時点の公式サポートはWindowsだけです。

## 正式対応

- X.com：ポスト本文、オリジナル画像、オリジナル動画
- メルカリ：商品画像
- Yahoo!フリマ：商品画像
- 楽天ラクマ：商品画像

## 実験的対応

- Reddit：投稿画像
- Civitai：画像、動画

実験的対応では、ページ構造やメディア形式により取得できない場合があります。

## Early Accessについて

v0.8.0はEarly Accessです。UIや補助機能は今後変更される可能性があります。特定サイトの将来のページ構造や仕様との永久互換を保証するものではありません。
