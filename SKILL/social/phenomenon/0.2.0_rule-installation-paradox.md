// mechanism owned by ① (SYNTAX ≠ SEMANTICS) and ② (self-exemption); NOT a cascade rung: ④ feeds INTAKE only

CORE := Install(Type1 → fresh host) → observable_contradiction

// THEOREM (installer's dilemma)
install(autonomy) requires command ∧ obey(command) ⇒ ¬autonomy   // the goal is defeated by its own transmission
Rule delivered by living node → node ∈ Scope(Rule) → ① fires at every utterance

// WITNESS (micro: education site)
"think for yourself!"        ↦ obedience ≡ non-autonomy (autonomy paradox)
"QUIET!" shouted loudest     ↦ act violates content (attitude paradox)
corporal punishment          ↦ "violence is wrong" taught by striking; teacher self-exempts ⇒ ②

// WITNESS (macro: same structure, fractal)
war under 大義名分           ↦ "do not kill" suspended by exemption clause; Weber: state = ② institutionalized
double_bind (Bateson)        ↦ "be autonomous" ∧ "do not rebel" issued simultaneously ⇒ learned helplessness

// WITNESS (institutionalized: initiation rite)
rite_of_passage (van Gennep) ↦ masked Initiator stages deliberate contradiction; ordeal installs Type1
scapegoat_role               ↦ Initiator absorbs the contradiction cost; hated by design, discarded after use

// ARCHITECTURE (boundary-resolver: abstractum-referent-immunity)
